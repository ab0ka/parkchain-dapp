## 1. Demo режимі — бірден іске қосу

`index.html` файлын браузерде ашыңыз. Басқа ештеңе қажет емес.

Жоғарыда **Demo** режимі тұрады: 24 орын (A·B·C аймақтары) жадта жұмыс істейді,
контракттың `require()` шарттары мен қате мәтіндері нақтысымен бірдей.
Интернет тек ethers.js кітапханасын жүктеу үшін керек.

> Бұл — кошелек, test ETH немесе deploy болмаған жағдайдағы сақтық нұсқа.
> Қорғауда логиканы толық көрсетуге жарайды.

## 2. Sepolia режимі — нақты блокчейн

### 2.1 Дайындық

1. **MetaMask** кеңейтімін орнатыңыз.
2. Желіні **Sepolia** деп таңдаңыз (MetaMask → Networks → Show test networks).
3. Тегін test ETH алыңыз: `sepoliafaucet.com` немесе `cloud.google.com/application/web3/faucet/ethereum/sepolia`.
   0.05 ETH жеткілікті.

### 2.2 Контрактты deploy жасау — А нұсқасы: бір батырмамен (ұсынылады)

Контракттың компиляцияланған bytecode-ы `index.html` ішіне салынған
(solc **0.8.26**, optimizer өшірулі, evmVersion `paris`, 11 385 байт).
Сондықтан Remix қажет емес:

1. `index.html` → **Sepolia** режимі → **Connect Wallet**.
2. **«⬆ Жаңа контракт deploy жасау»** батырмасын басыңыз.
3. MetaMask deploy транзакциясын растауды сұрайды (≈0.003 ETH газ) → **Confirm**.
4. Контракт адресі автоматты толтырылып, қосылу да өзі орындалады.
5. Owner панелінен **«24 орын (A·B·C)»** басып, тұрақты толтырыңыз.

> Deploy жасаған аккаунт автоматты түрде `owner` болады.

### 2.3 Контрактты deploy жасау — Б нұсқасы: Remix арқылы

1. `remix.ethereum.org` сайтын ашыңыз.
2. `contracts` бумасында жаңа файл жасап, атын `ParkingManager.sol` қойыңыз.
3. Осы репозиторийдегі `ParkingManager.sol` мазмұнын толық көшіріп қойыңыз.
4. **Solidity Compiler** қойындысы → нұсқасы **0.8.20** немесе жоғары → **Compile**.
5. **Deploy & Run** қойындысы:
   - Environment: **Injected Provider — MetaMask**
   - Желі Sepolia екеніне көз жеткізіңіз
   - Contract: `ParkingManager`
   - **Deploy** → MetaMask-та растаңыз
6. Deployed Contracts бөлімінен **контракт адресін көшіріңіз** (`0x…`).

### 2.4 Интерфейсті қосу (Б нұсқасынан кейін)

1. `index.html` ашыңыз → жоғарыдан **Sepolia** режимін таңдаңыз.
2. **Connect Wallet** → MetaMask-та аккаунтты растаңыз.
3. Контракт адресін өріске қойып, **Контрактқа қосылу** басыңыз.
   (Адрес браузерде сақталады, келесі ашқанда өзі толтырылады.)

### 2.5 Орындарды толтыру

Deploy жасаған аккаунт — `owner`. Төменде **owner панелі** шығады:

- **«24 орын (A·B·C)»** батырмасы — үш транзакциямен 24 орын қосады
  (A — 0.003, B — 0.002, C — 0.001 ETH/сағ).
- Немесе аймақ/сан/баға өрістерін қолмен толтырып, **Орындарды қосу**.

## 3. Қорғауда не көрсету керек

| Қадам | Нәтижесі |
|---|---|
| Бос орынды басып, 2 сағ таңдап, **Бронь жасау** | MetaMask → транзакция → орын сарыға айналады, `SpotBooked` оқиғасы журналда |
| Сол орынды қайта брондауға тырысу | Батырма бұғатталған; Remix арқылы шақырса — `revert: Spot already booked` |
| Басқа аккаунттан бөтен бронды босатуға тырысу | `Босатуға рұқсат жоқ` → контрактта `revert: Not allowed` |
| Өз орныңызды **босату** | Орын қайта көк болады, `SpotReleased` оқиғасы |
| Аймақ сүзгісі, «бос / бос емес» есептегіші | Бәрі `getAllSpots()` — **view**, газ төленбейді |
| owner панелінен **Қаражатты шығару** | Жиналған төлем owner-ге қайтады |

### Негізгі require() шарттары

| № | Шарт | Қате мәтіні |
|---|---|---|
| R1 | `spots[id].id != 0` | `Spot not found` |
| R2 | `!spots[id].occupied` | `Spot already booked` |
| R3 | `msg.value == pricePerHour * hoursCount` | `Wrong payment` |
| R4 | `driver == msg.sender \|\| (isOperator && expired)` | `Not allowed` |

Қосымша: `Only owner`, `Hours must be 1..24`, `Price must be above zero`.

### Жиі қойылатын сұрақтарға жауап

- **dApp пен кәдімгі веб-қосымшаның айырмашылығы?** Мұнда сервер де, дерекқор да жоқ.
  Ережелер контрактта орындалады, деректер блокчейнде сақталады, оны ешкім қолмен өзгерте алмайды.
- **ethers.js не істейді?** ABI арқылы функция шақыруын дайындайды және нәтижені оқиды.
- **ABI не?** Контракт функцияларының аты, параметрлері мен қайтаратын мәнін сипаттайтын JSON.
  Ол `index.html` ішінде `ABI` массиві ретінде жазылған.
- **Қай функция газ алады?** Күйді өзгертетіндері: `addSpot`, `addSpots`, `bookSpot`,
  `releaseSpot`, `setOperator`, `withdraw`. `getSpot`, `getAllSpots`, `getFreeSpots` — **view**, тегін.

## 4. Ескертпелер

- Уақыт `block.timestamp` арқылы есептеледі — дәлдігі блок уақытына байланысты (бірнеше секунд).
- Төлем контрактта сақталады, босатқанда қайтарылмайды — оны owner `withdraw()` арқылы алады.
- `string zone` газды көбірек жейді; оптимизация керек болса `bytes32` нұсқасына көшуге болады.
- Бұл — **оқу жобасы**, нақты тұрақта пайдалануға арналмаған.
